# Sistema de Gestión de Citas Médicas

Proyecto de la asignatura Arquitectura de Sistemas Computacionales.

## Problema

El sistema permite gestionar citas médicas de manera eficiente, conectando pacientes con profesionales de la salud, optimizando la asignación de horarios y reduciendo los tiempos de espera.
